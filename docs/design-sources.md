# Research Skill Design Sources

Reviewed on 2026-09-27. These are public community projects, including projects whose names contain Nature; that naming does not establish Nature Portfolio authorship or endorsement. This comparison concerns the inspected instruction files. No external package or script was installed or executed, and no performance ranking was measured.

The changes are written for codex-research's existing question-led, interactive workflow. External files remain research material, not runtime instructions or dependencies. Existing access states, claim-specific evidence, lawful acquisition, consent, and adaptive stopping remain authoritative within this Skill.

## Local integration

- [Search strategy](../references/search-strategy.md#screening-decisions): eligibility, pending decisions, and branch-aware citation expansion.
- [Synthesis and research design](../references/synthesis-and-research-design.md): a task-sized evidence view, theme-level judgment, and the observations that could discriminate candidate explanations.
- [Publication audit](../references/evidence-reasoning.md#publication-audit): three separate citation checks and draft-to-source reconciliation.
- [Research state](../references/research-state-and-delivery.md#update-behavior): reusable rejected pairings and updates to affected conclusions. Incremental date-window handling is a local extension, not a claim that an upstream project implemented it.

The study-design prompts are also a local integration of the existing hypothesis and experimental-transfer contracts. They do not validate proposed sample sizes or experimental conditions.

The entrypoint remains brief and routes to conditional detail, consistent with [OpenAI's Skill guidance](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra). No external source needs to be fetched each time the Skill runs.

## Validation boundary

Repository validation checks metadata, links, fixtures, and local regressions. Synthetic behavior exercises can show particular decisions on supplied records; they do not establish improved real-world recall, scientific correctness across fields, or comparative superiority. See [evaluation guidance](../evals/README.md) for actual execution status.
