# codex-research 目标与执行审核

日期：2026-10-05。对象：当前工作区的 Skill 入口及八份运行参考文档，包含尚未发布的维护修改。

## 总体评价

**值得使用，对问题梳理、文献筛选、原文核查和综述事实把关有较大的预期帮助。文档链路总体满足要求，不需要整体重写。**最强的部分是文献评价、原文阅读和论点—证据核对；相对薄弱的是把若干研究组织成“认识怎样发展”的研究脉络。

作为阅卷者，我看的是目标有没有对应的行动、行动有没有形成可用结果、结果能否接到下一步，而不是出现了多少条规则。作为使用者，我希望最后知道：研究什么、怎样找相关材料、哪些结果值得信任、原文证据在哪里、可以得出什么结论、还缺什么，以及这个领域怎样发展到现在。当前设计对这些问题大多有实质帮助。

本轮采用文档通读、两份分工审读、主审回原文裁决及原始标准参照。**没有运行测试、评测、检查脚本或 MCP 实测。**下面的“满足”表示文档目标和执行办法有对应，不表示已经证明模型每次都能执行正确，也不表示检索召回率或节时收益已经测量。历史评测不作为本轮通过依据。

## 标准参照及适用方式

| 参照 | 本轮采用的判断准则 | 适用边界 |
|---|---|---|
| [PRISMA 2020 扩展清单](https://www.prisma-statement.org/s/PRISMA_2020_expanded_checklist-yc78.pdf)，条目 4、5、6—9、10、13 | 问题和纳入范围明确；来源、选择、提取与综合能够追踪；综合方法和限制可解释。 | 属于系统综述报告标准；不能把普通调研直接判为完成了正式系统综述，也不强制所有学科套用 PICO。 |
| [PRISMA-S 原始论文](https://link.springer.com/article/10.1186/s13643-020-01542-z)，条目 1、5、8—9、12、13、16 | 数据库与平台、检索式及限制、检索日期、引文扩展路径、更新和去重有记录依据。 | 报告透明度不等于搜索充分或召回率高；本轮借其审查可追踪性。 |
| [Cochrane 第 7 章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-07)，§7.1.1—7.1.2、7.3 | 评价具体结果，区分偏倚、不精确、适用性和信息缺失，给出判断依据。 | 借用结果级评价原则，保留材料、理论、算法、观察研究各自的证据要求。 |
| [Cochrane 第 12 章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-12)，§12.2—12.4 | 按可比较的对象和问题组织证据，解释综合办法及条件，避免只逐篇复述或按显著性投票。 | 不要求没有合适数据的任务做合并分析；条件式定性依赖检查不是已执行的统计敏感性分析。 |
| [NLM PubMed 官方检索说明](https://pubmed.ncbi.nlm.nih.gov/help/)，MeSH 字段与相关索引过滤说明 | 主题词的含义、层级展开与索引状态会影响检索范围，应与适当自由词互补。 | 是受控词检索的具体例子，不把 PubMed 语法强加给其他接口。 |

研究脉络部分没有以 PRISMA 当作“科学史重建标准”；其评价来自用户明确要求，以及当前文档中主题关系与实际发展关系之间的执行落差。

## 问题裁决与已落实改进

### 1. 必须补齐本轮要求：研究脉络的重建方法

**触发场景：**用户要求研究进展、主要突破、演化路线或领域入门。原有指引容易停在“有哪些方向、各方向有什么论文”，尚不足以回答“认识是怎样变化的”。

**已有规则的反证：**主题联系、已取得进展、条件和剩余问题确实已经存在，因此不能报告为“完全没有研究脉络”。缺的是目标到执行之间的桥梁。

**本轮修改：**在 [综合指南](../references/synthesis-and-research-design.md#explain-research-development-and-progress) 添加条件式方法，按“早期问题／基线 → 方法或发现 → 后续验证、修正、反例 → 当前边界”组织相关分支。节点按对问题认识的改变选择，核对日期、版本和研究关系；从原文确认继承、测试、扩展或反驳，不凭年份、被引或图边声称“首次”“奠定”“取代”。同步了入口路由和状态记录位置。

**改善目标：**使用者应能看懂每个重要转折改变了什么，而不是只得到时间排序的论文列表。具体效果仍取决于实际资料和执行。

### 2. 值得增强：关键词扩展的语义边界

**触发场景：**材料、物种、技术或指标存在相似名称、上下位概念和缩写歧义；使用带受控主题词的来源。把近邻词都当同义词会改变检索或解释对象，单靠后续相关性筛选不一定能找回检索时漏掉的材料。

**已有规则的反证：**词义、查询解释、噪声诊断和筛选本来已受约束。这是对关键词阶段的补强，不是新增一整套关键词流程。

**本轮修改：**在 [概念与检索演化](../references/search-strategy.md#concept-and-query-evolution) 中区分真正同义词、上／下位概念和邻近但不同对象；必要时查正式术语源或原文定义。说明受控词范围、自动展开和未完成索引的影响，并与适当自由词互补。探索性扩大查询不自动扩大纳入标准，也不授权在不同对象间转移结果。

**改善目标：**减少“查的是相邻对象，写成了目标对象”的风险，同时保留通过更宽检索发现相关研究的空间。

### 3. 条件性增强：关键结论的依赖关系

**触发场景：**决定研究方向的结论主要依赖一项研究、多篇独立性未知的报告，或一个共同的间接前提。

**已有规则的反证：**独立性、直接性、比较、权衡及不确定性已有较充分说明，不应把这项报为缺少可靠性评价。

**本轮修改：**在 [综合判断](../references/synthesis-and-research-design.md#turn-the-view-into-a-synthesis) 中增加简短定性检查：对有实质争议或较弱的关键依据，若不采纳它或改变有关假设，结论仍成立、需要收窄还是无法判断？标明受影响结论和最有价值的补足证据。保留单一研究能够支持有限发现的情况，不随意删除扎实证据，不强制统计分析或每句话检查。

**改善目标：**防止看似有多篇引用的综合结论实际只依赖一个脆弱来源，并使“下一步补什么”更有针对性。

README 也已与“先相关性，再用期刊／被引作为辅助可信背景”的现行规则对齐。上述修改仅限 Skill 文档和本审核报告，没有改动工具、评测或运行配置。六份变更运行文档已同步到此前安装的 Skill，未运行验证脚本。

## 作为使用者，我会怎样用它

| 实际需要 | 我希望拿到的结果 | 文档设计能够提供的帮助 |
|---|---|---|
| 刚进入陌生领域 | 问题和术语解释、主要分支、代表性原始研究、认识的关键变化、当前边界。 | 省去自己先选专题或搜词的负担；本轮补齐脉络结构后，领域地图能进一步回答“为什么发展到现在”。 |
| 判断一个具体机制 | 直接观察、作者解释、替代机制及能区分它们的证据，附原文定位。 | 帮助较强：不会仅靠一篇“看起来相关”的论文或机制图确认机制。 |
| 准备事实准确的综述 | 每个主题的可比较证据和有条件结论，保留负面结果、原文冲突及待查材料。 | 帮助较强：把对象、指标、条件、引用和论点连起来，减少摘要替代证据、错配引用与重复计数。 |
| 决定下一步研究 | 最近的已知工作、哪个具体问题仍未解决、缺什么证据、什么观察有辨别价值。 | 有实质帮助：先查是否已有邻近／相反证据，再提出问题；不会仅为了新颖而拼接主题。 |

价值最主要来自减少术语摸索、无效搜索、重复核查和错误归因，并保留可继续工作的证据链。这里是根据文档做出的使用价值判断，没有测得时间节省、漏检率或事实错误率。

## 保留的边界与停止判断

1. 不再增加一套通用分数、固定数据库数量、固定论文数或普遍强制整篇阅读。现有细则已经较密，优先按当前动作加载和复用已核实材料。
2. 文档不能创造不存在的全文权限、准确索引或稳定连接。具体来源受限时，仍须保留其影响，不能把已成功的其他来源写成全面覆盖。
3. 对研究史“首次／彻底解决”、领域共识、因果机制和全领域空白仍应使用相称的证据。关键科研判断需要实际原文核实。
4. 本轮已完成目标—执行审核和有依据的文档改进，按用户要求停止，不以验证改进为由继续运行测试。

**阅卷结论：基本能力链路合格，研究脉络原有执行指引需补强；已落实针对性修订。使用者评价：值得用，特别适合问题驱动的文献调研和综述证据核验。**本轮完成的是文档充分性审核与修订，实际行为效果未在本轮测量。
